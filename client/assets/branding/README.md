# Carpeta de Logos y Branding de GamesBoy.net

Coloca aquí tus archivos con estos nombres exactos:

1. `logo-white.png` (o `logo-white.svg`):
   - Logo con texto blanco y detalles en Cyan (para el header oscuro y landing principal).

2. `logo-dark.png` (o `logo-dark.svg`):
   - Logo con texto oscuro y detalles en Cyan (para fondos claros, comprobantes o facturación).

3. `icon.png` (o `icon.svg`):
   - Isotipo / Ícono del logo (para Favicon de la pestaña del navegador, vista móvil y avatar oficial).

4. `favicon.ico` (opcional):
   - Favicon directo si lo tienes en formato .ico (si no, usamos `icon.png`).
